# Service API

Contract that a service provider must implement so tsuru can create, bind and manage
instances. See [Building your service](../services/build.md) and
[Service API workflow](../services/api.md) for the narrative. The source of truth is
[`docs/reference/service_api.yaml`](https://github.com/tsuru/tsuru/blob/main/docs/reference/service_api.yaml).
