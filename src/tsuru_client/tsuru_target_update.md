## tsuru target update

Updates an existing entry in the list of available targets

### Synopsis

Updates an existing entry in the list of available targets

```
tsuru target update <label> <target> [--set-current|-s] [flags]
```

### Options

```
  -s, --set-current   Add and define the target as the current target
  -h, --help          help for update
```
